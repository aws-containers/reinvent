# CON402 — Amazon EKS: Infrastructure as code, GitOps, or CI/CD

**AWS re:Invent 2026** · Chalk Talk · 400 - Expert

How to deliver to Amazon EKS — infrastructure as code, GitOps, or CI/CD — and where each fits. These resources go deeper on each approach and give you a working reference to start from.

## Recommended today — a ready-to-use reference platform
The approach we recommend now: instead of wiring IaC, GitOps and CI/CD together yourself, start from best-practices blueprints that already combine all three into one working platform.
- [Platform Engineering on EKS — self-paced workshop](https://catalog.workshops.aws/platform-engineering-on-eks/)
- [aws-samples/appmod-blueprints](https://github.com/aws-samples/appmod-blueprints) — AWS App Modernization Blueprints: our recommended GitOps-driven EKS platform, with IaC and CI/CD wired together.
- [awslabs/open-agentic-platform](https://github.com/awslabs/open-agentic-platform) — Open Agentic Platform (OAP).
- [Interactive demo (Storylane)](https://app.storylane.io/share/219m06juq81g)
